## 2. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 技术栈 | 原生 HTML + CSS + JavaScript（ES6） | 单文件交付、零依赖、双击即用 |
| 渲染方式 | DOM + CSS `transform` / `opacity` 动画 | 元素少，无需 Canvas，坐标可控 |
| 动画驱动 | CSS `transition` / `@keyframes` 为主，JS 只切类名 | 保证流畅，避免 JS 逐帧 |
| 打字机 | `requestAnimationFrame` + 时间累积 | 比 `setInterval` 稳，且便于中途取消 |
| 音频 | `Audio` 对象池（3 实例轮询） | 0.11s 短音可重叠播放，不打断 |
| 字体 | **系统默认字体**，不引用也不内嵌字体 | 需求禁止联网 |
| 显示缩放 | 最外层 `transform: scale()` 等比适配窗口 | 内部坐标保持 1200×896 不变 |

## 6. 核心实现方案

### 6.1 画布与坐标系（含等比缩放）

`#stage` 固定 `width:1200px; height:896px; position:relative; overflow:hidden`。所有子元素 `position:absolute` + 精确 px，**不使用 flex/auto 布局**，保证坐标可预测。

外层由 `#viewport` 负责居中与等比缩放：

```css
html, body { margin:0; height:100%; overflow:hidden; background:#000; }
#viewport  { position:fixed; inset:0; display:flex;
             align-items:center; justify-content:center; }
#stage     { width:1200px; height:896px; position:relative;
             overflow:hidden; transform-origin:center center; }
```

```js
function fitStage() {
  const s = Math.min(innerWidth / 1200, innerHeight / 896);
  stage.style.transform = `scale(${s})`;
}
addEventListener('resize', fitStage);
fitStage();
```

**行为约定**：

| 窗口情况 | 缩放比 | 效果 |
|---|---|---|
| 窗口 ≥ 1200×896 | `s = 1` | 1:1 原始尺寸居中，**不放大** |
| 窗口 < 1200×896 | `s < 1` | 整幅等比缩小，居中显示，`overflow:hidden` 不出现滚动条 |

**关键点**：

- 缩放只作用于最外层 `#stage`，**内部所有坐标、相对位置、字号比例完全不变**
- 使用 `Math.min` 而非 `Math.max`，保证画面完整可见且永不超过原始尺寸
- ⚠️ 截图验收时（§11.2）**必须先把窗口设为 ≥1200×896**，使 `s = 1`。否则 `getBoundingClientRect()` 返回的是缩放后的值，量出来的坐标会与文档不符

### 6.2 资源预加载

```
Promise.all([ 7 张图片 new Image() , 音频 canplaythrough ])
  → 全部就绪 → 移除 loading 黑屏 → 进入 S0
```

- 加载期间画面为纯黑（素材中无 loading 图）
- 总体积约 3.5MB（`bg-start` 2MB + `bg-room` 1.5MB），本地加载瞬间完成

### 6.3 状态机

用单一状态变量 + 集中式切换函数，避免散落的 flag：

```
S0_LOADING → S0_TITLE → S1_ROOM → S2_WAIT_GO_1
           → S3_SUITCASE → S3_WAIT_GO_2 → S4_HINT → S5_BLACK
```

每次进入状态调用 `enterState(name)`，内部统一处理：显示/隐藏哪些元素、是否允许点击、播放哪段打字。

**点击许可**由一个函数集中判定 `canClick(el)`，避免打字中误触。

### 6.4 打字机

```js
function typeText(str, speed = 40) {
  // rAF + 时间累积，逐字符写入 #chat-text
  // 返回 Promise，resolve 时表示打完
}
```

- 速度 40ms/字（需求区间 35–45ms 中值）
- 内部持有 `token`，再次调用时作废旧任务，防止两句文本串台
- **必须原样保留**弯引号：`Wow! I’m traveling somewhere new. Let me get ready.`

### 6.5 对话弹窗滑入

```css
#chat { top:400px; transform: translateY(110%); transition: transform .6s ease-out; }
#chat.in { transform: translateY(0); }
```

用 `translateY(110%)` 确保初始完全在画布外（`overflow:hidden` 裁掉），避免露出上边缘。

### 6.6 按钮的出现与隐藏（Q4 核心）

- `btn-go` 初始 `opacity:0; pointer-events:none`
- **仅在 `typeText()` 的 Promise resolve 之后**才加 `.in` 类淡入
- 打字期间按钮：不可见 + `pointer-events:none` + 不参与点击判定（三重保险）
- 点击后立即移除 `.in` 并进入下一状态

### 6.7 引导手循环动画

```css
@keyframes tap {
  0%,100% { transform: scale(1); }
  50%     { transform: scale(.85); }
}
#hand { transform-origin: 18% 8%; animation: tap .9s ease-in-out infinite; }
```

- `transform-origin` 设在**指尖位置**（左上角附近），让缩放看起来是「手指在按」，而非整张图抽搐
- `pointer-events:none`，纯指示

### 6.8 音效

- 预创建 3 个 `Audio('audio/toggle.wav')` 实例，轮询播放
- 触发点：`btn-start`、`btn-go`（两次）、`suitcase` 的有效点击
- 浏览器自动播放策略：首次交互即点击 START，此后不再受限；在 S0 阶段不做任何自动播放

### 6.9 防连点

- 全局 `busy` 标志：转场/打字期间为 `true`
- 推进类点击额外加 **300ms 冷却**
- 所有可点击元素统一走 `onClick(el, handler)` 包装函数，集中加锁

### 6.10 转场与全黑

- 第一幕 → 第二幕：`#act1` 淡出 400ms，同时 `#act2` 淡入 400ms（交叉过渡，不出现白屏）
- 结束：`#blackout` 由 `opacity 0 → 1`，700ms，黑屏后**静止**，不下发任何后续动作；`#act3-slot` 保持空

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| **B1** | 窗口大于 1200×896 时画面被**放大** | `fitStage()` 的 `Math.min` 没有上限 | 改为 `Math.min(w/1200, h/896, 1)` |

| **B3** | 内部坐标系被挤成 **1174×803**，所有 `right/bottom` 定位基准错误 | `#stage` 作为 flex 子项被 `flex-shrink` 压缩 | `#stage{flex:0 0 auto}` |

> B1/B2 是纯逻辑问题，B3 由 flex 默认收缩引起。三者都只有在真实浏览器里跑起来才会暴露，静态审阅代码看不出来。

### 13.4 引导手落点修正
