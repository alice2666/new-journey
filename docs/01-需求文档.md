# 《New Journey》叙事互动 Demo — 需求文档

- 文档版本：v1.3（确认缩放/验收/字体三项；配套 `docs/02-开发计划.md`）
- 编写日期：2026-09-30
- 当前阶段：**需求已确认（尚未开发）**
- 交付目标：单文件纯静态 HTML 叙事小游戏（本阶段仅覆盖第一幕、第二幕）

---

## 1. 项目概述

一个以「收拾行李出发去旅行」为主题的点击式（Point-and-Click）叙事 Demo。玩家通过点击推进剧情，全程由本地美术素材 + 打字机对话 + 引导手提示驱动，无分支、无失败状态，属于线性线性叙事体验。

情节概要：主角 Luna 站在车站站台（第一幕）→ 点击 START → 回到房间开始收拾行李，发现新买的行李箱没有任何标记、容易被别人拿错（第二幕）→ 点击行李箱 → 画面转黑（本阶段结束）。

## 2. 技术约束（硬性要求）

| 项 | 要求 |
|---|---|
| 交付形态 | 单个 `index.html`，纯静态，零依赖、零构建 |
| 运行方式 | 双击打开（`file://`）即可运行，也支持本地 HTTP 服务 |
| 画布尺寸 | **内部坐标严格 1200 × 896**，所有元素按此坐标系绝对定位 |
| 显示适配 | 窗口小于 1200×896 时，**整幅画面等比缩放**以适配窗口（仅显示层缩放，内部坐标与元素相对位置完全不变） |
| 素材引用 | 使用相对路径引用本地 `assets/`、`audio/`，不使用外链、不联网 |
| 字体 | 使用**系统默认字体**，不引用、不内嵌任何网络字体 |
| 后台任务 | **不得在后台生成任何任务/子 Agent**，一次性产出完成 |
| 兼容性 | 现代浏览器（Chrome / Edge），桌面端鼠标点击操作 |
| 资源预加载 | 所有图片、音频在开场前预加载完成，避免演出中闪现空白 |

### 2.1 坐标系约定

以画布左上角为原点 `(0, 0)`，x 向右递增，y 向下递增。文档中同时给出「距底部像素」换算，便于对齐。

- 画布：`W = 1200`，`H = 896`
- 水平居中轴：`x = 600`
- 换算公式：`top = 896 - 距底部距离 - 元素高度`

> 该坐标系为**内部逻辑坐标**，与窗口大小、显示缩放无关。窗口缩放只作用于最外层显示，本文档所有像素值均按此坐标系书写。

## 4. 第一幕：车站站台

### 4.1 演出流程

1. `bg-start.png` 出现 —— 全屏铺满，作为开场画面直接呈现（建议淡入 300–600ms）。
2. `btn-start.png` 出现 —— 在背景稳定后淡入（延迟约 400ms，淡入 300ms）。

### 4.2 元素定位

| 元素 | 尺寸 | 定位规则 | 计算结果 |
|---|---|---|---|
| `bg-start.png` | 1200 × 896 | 全屏，左上角对齐 | `left: 0, top: 0` |
| `btn-start.png` | 227 × 97 | **水平居中**，**底边距画布底部 170 px** | `left: 486.5`，`top: 629`（即 `bottom: 170`） |

### 4.3 交互

- 点击 `btn-start.png`：
  1. 播放 `toggle.wav`
  2. 第一幕整体淡出
  3. 进入第二幕

### 4.4 按钮态

需要 3 个视觉状态，均基于同一张图实现，避免额外素材：

| 状态 | 效果 |
|---|---|
| 默认 | 原图 |
| 悬停 | 轻微放大（1.05）并加投影 |
| 按下 | 缩小（0.95），模拟按下反馈 |
| 鼠标指针 | `cursor: pointer` |

## 5. 第二幕：房间

第二幕是本阶段主体，包含 5 个连续阶段（S1–S5），全部由点击驱动。

### 5.1 阶段总览

| 阶段 | 状态 | 画面内容 | 触发条件 | 下一步 |
|---|---|---|---|---|
| S1 | 房间入场 | `bg-room.png` 淡入；`chat.png` **从下往上滑入**并贴底；打第一句 | 第一幕点击 START | 第一句打完 |
| S2 | 首次推进 | `btn-go.png` 淡入（打字完才出现） | 点击 GO | 清空对话 → 出现行李箱 |
| S3 | 行李箱出现 | `suitcase.png` 出现在右下角；**清空后**打第二句 | 点击 GO | 第二句打完 |
| S4 | 引导提示 | `btn-go.png` 再次淡入 → 点击后 `hand.png` 出现并循环点按；`suitcase.png` 变为可点击 | 第二句打完 → 点击 GO | 点击行李箱 |
| S5 | 结束 | 行李箱点击生效 → 画面渐变全黑 → 静止 | 点击行李箱 | 本阶段结束 |

### 5.2 S1 — 房间入场

| 元素 | 定位 |
|---|---|
| `bg-room.png`（1200×896） | `left: 0, top: 0`，全屏；淡入 400ms |
| `chat.png`（1200×496） | 水平居中，**最终位置贴底**（`bottom: 0`，即 `top: 400`）；初始位置在画布下方完全不可见（`translateY(100%)`），用 500–700ms 缓动（ease-out）**自下而上滑入** |
| `btn-go.png` | **此阶段不可见**，需等第一句打字完成后才出现（见 §5.3） |

**打字机对话文本（第一句）**：

```
Wow! I’m traveling somewhere new. Let me get ready.
```

- 逐字显示，速度约 **35–45 ms/字**（可按手感微调）
- **文本安全区（v1.1 实测素材后订正，画布坐标）**：`left 540` / `top 725` / `width 500` / `height 150`
  - 约束来源：角色立绘占据左侧 `x < 330`；「Luna」姓名牌占据 `x 300–516 / y 691–750`；GO 按钮占据 `x 1062–1100 / y 799–846`
  - 排版：`font-size: 28px`、`line-height: 1.35`，最多 3 行
  - 详见 `docs/02-开发计划.md` §5.1
- 字体：**使用系统默认字体**（不引用、不内嵌任何网络字体），颜色取深蓝色以贴合素材风格

### 5.3 S2 — 首次推进按钮

- `btn-go.png`（38×47）**必须在第一句打字全部完成后**才淡入出现；打字过程中该按钮**不存在于画面**（不可见且不可点击）
- **定位（Q2 已确认）**：距画布**右边 100 px**、距**底边 50 px**
  - 换算结果：`left = 1062`，`top = 799`
- 按钮出现后即可点击，点击即推进剧情（**不存在「跳过打字」逻辑**）

### 5.4 S3 — 行李箱出现

- 在点击 GO 后，`btn-go.png` 隐藏，`suitcase.png`（225×414）出现于**画面右下角**
- 出现方式：淡入 + 轻微上浮（约 300–500ms）
- **定位（Q3 已确认）**：距画布**右边 50 px**、距**底边 30 px**
  - 换算结果：`left = 925`，`top = 452`
  - ⚠️ 该坐标为素材实际落点，渲染后需目测确认是否与背景地板线自然贴合

**打字机对话文本（第二句）**：

```
This brand-new suitcase has no marks. Someone might take it by mistake.
```

- **Q5 已确认**：点击第二幕的 GO 按钮后，**先清空第一句文本**，再出现并逐字播放第二句
- 第二句打字期间，`btn-go.png` **再次隐藏**，打完字后才重新出现

### 5.5 S4 — 引导手提示

- 在点击 GO 后，`btn-go.png` 隐藏，`hand.png`（165×161）出现在**行李箱附近**
- 素材姿态：手指指尖朝**左上方**，因此引导手应置于**行李箱偏右下/前方**的位置，使指尖落向箱体
- **建议位置**：`left ≈ 940`、`top ≈ 660`（叠加在行李箱下部，指尖指向箱面）。⚠️ 需渲染后目测微调，此项为唯一保留的微调项
- 动画：循环「点按」效果 —— 缩放 `1.0 → 0.85 → 1.0` 或轻微下压位移，周期约 800–1000ms，`infinite`
- 引导手**不可点击**，仅作指示（`pointer-events: none`）
- 此阶段画面上的**唯一可点击目标为行李箱**

### 5.6 S5 — 结束

- 点击 `suitcase.png`：
  1. 播放 `toggle.wav`
  2. 引导手隐藏
  3. **画面整体渐变全黑**（约 600–900ms 淡出到纯黑 `#000`）
- **Q6 已确认**：全黑后**静止黑屏**，不做跳转、不显示文字、不提供返回按钮
- 黑屏层内预留一个空的结束容器（如 `<div id="act3-slot">`），便于后续挂载第三幕

### 5.7 第二幕可点击元素汇总

| 阶段 | 画面上可点击元素 | 出现条件 | 点击后行为 |
|---|---|---|---|
| S1 房间入场 | 无 | — | — |
| S2 首次推进 | `btn-go.png` | 第一句**打完字后**才出现 | 播放音效 → 清空对话 → 行李箱出现并开始打第二句 |
| S3 行李箱出现 | `btn-go.png` | 第二句**打完字后**才出现 | 播放音效 → 隐藏按钮 → 引导手出现 |
| S4 引导提示 | `suitcase.png` | — | 播放音效 → 全黑 |
| S5 结束 | 无 | — | 静止黑屏 |

> **核心规则（Q4 已确认）**：`btn-go.png` 必须等当前这句对话**逐字打完**后才出现。打字进行中，该按钮在画面上完全不存在（既不可见也不可点击），不存在「点击跳过打字」的行为。

## 6. 动画与交互规范

| 项目 | 规范 |
|---|---|
| 淡入 / 淡出 | 300–600 ms，`ease-out` |
| 对话弹窗滑入 | 自下而上，500–700 ms，`ease-out` |
| 打字机速度 | 35–45 ms/字 |
| 引导手循环 | 800–1000 ms/循环，无限循环 |
| 音效触发 | 点击生效瞬间播放，允许重叠 |
| 按钮出现时机 | `btn-go.png` 仅在当前对话**逐字打完**后淡入；打字期间不在画面中 |
| 点击屏蔽 | 动画进行中锁定点击，防止重复触发（防连点）；推进类点击需加 300ms 冷却 |
| 鼠标反馈 | 所有可点击元素 `cursor: pointer` + hover / active 视觉反馈 |
| 图层顺序 | 背景（0）→ 道具（10）→ 引导手（20）→ 对话弹窗（30）→ 按钮（40）→ 遮黑层（100） |
