# New Journey 项目长期约定

## 项目本体

- 单文件纯静态叙事小游戏，交付物只有 `index.html`（原生 HTML/CSS/JS，零依赖、零构建、零网络请求，双击即用）。画布固定 **1200×896**，窗口更小时由 `#stage` 的 `transform: scale()` 等比缩放（上限 1）。
- 素材全在 `assets/screen1..7`，路径用**正斜杠**。`screen1~5` 已接入（第五幕 v2.10 交付）；**`screen6`/`screen7` 经 Q41 确认属第六幕「拼碎纸 / 修复古画」**，玩法待用户描述，不接入。

## 文档分工

- `docs/01-需求文档.md` 写**做成什么样**；`docs/02-开发计划.md` 写**怎么做**。两份**不重复数值**：计划凡涉及数值都标需求章节号。改一份后检查另一份。

## 协作流程

- 用户分轮推进：给需求 → 要求「整理/更新文档」→ **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 最后才说「开工」。每轮后：追加日志到 `.workbuddy/memory/YYYY-MM-DD.md`，用 `present_files` 给文档预览。
- **答复语义要「顺着 Q 的选项」读**（已踩两次）：**Q 是选择题时，答复里的描述就是「选项」**。信号：说「**是** XX」＝确认；「**怎么** XX / XX **不对**」＝报缺陷；**没有否定词＝确认**。实例：Q「BGM 停止点要不要后移？」答「在第四幕末停掉、后面没 BGM」→ **选「不动」**（我误读成「要修的缺陷」，被纠正）。**兜底：拿不准默认「不动」**。

## 测试约定

**做法详见技能 `web-visual-verify-cdp`**。此处只留硬约束：

- `node .workbuddy/tools/test.js`（CDP 直连 Edge；**14 用例 434 项**）＋ `boot-check.js`（4 场景 19 项；**注入不可撤销排最后**）。断言前视口钉成 **1200×896**（`s = 1`）。
- 几何读**布局坐标**（`offsetParent` 链累加），**不要** `getBoundingClientRect()`（被 transform 污染）。
- **「动作」需求必须采样 `computed transform`**（D5）：`offsetTop` 只反映**布局位置** —— 「**在哪儿**」≠「**怎么到那儿**」。`goal01` 要「落下」写成「原地放大」，**23 条断言全绿**。解析 `matrix()` 按槽位取数（6 → `n[4]/n[5]`；16 → `n[12]/n[13]`）。
- **`gate` 用例专测「整幕可见性」+「堆叠隔离」**；⚠️ `elementFromPoint` 测不出（未激活幕 `pointer-events:none`）。

## 实现约定

- **幕必须「门控 + 隔离」两件套（缺一不可）**：
  - **门控**：每个 `.scene` 自带 `opacity:0` + 激活类，否则常驻可见元素会连 `z-index` 一起盖住当前幕（D4：`#act3` 漏门控，241 项断言全绿）。**新增幕必须补并让 `gate` 覆盖。**
  - **隔离**：`.scene` 必须 `isolation:isolate`（D6）。**成因**：`.active` 把容器 `opacity` 从 0 改 1 → **堆叠上下文消失** → 幕内高 z-index 元素跑到 `#stage` 层抢层级。实例：`#act4` 的 `#goal01`(95) 盖住 `#act5`(5)，画面是「城堡视频叠 Goal 卡片」，**几何断言全绿**。→ **全屏层 + 幕内高 z-index 的结构，每层都要 isolate。**
- **「终点」会移动，副作用必须复查**（v2.12）：凡「某事件＝全片终点」（如「点 `Continue` 停 BGM」），终点一后移，依赖它的副作用**静默失效**且无断言报。**改流程顺序时搜「终点/结束/停止/全黑」。**
- **素材目录里没被提到的图，先观察再问、不揣测玩法**：登记进文档 + 列为 Q，不动它们。
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 在幕间注入（HTML `preload="none"` 且不带 src）。**新幕视频可整套照搬第三幕**（`object-fit: fill` 铺满）；**但「定格图常驻 + 视频淡出露出」照搬不了**（`screen5/`、`screen6/` 均无户外定格图）→ 走「视频末帧延续 → 淡出 → 黑场 → 新图淡入」，**别在 `ended` 就淡出**（会透出下层幕残留）。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100 / slot 110。**锁模型三层**：`busy`（演出期屏蔽一切点击）/ `animLock`（贴纸落定·飞回 250ms）/ `placing`（待放置）；进事件驱动玩法循环前必须把 `busy` 置回 `false`。
- **贴纸落点判据（Q25）**：判「**整张贴纸（142×119 未旋转外框）完整落在可显示范围**」，**不是**「中心在范围内」。**跟随高亮 `.on-body` 与落点判定必须共用 `inBody()`**。用户截图有裁切偏移、缩放比不等，**先标定再换算**。
- **浏览器最低 Chrome 41+ / Edge 15+ / Firefox 44+**：脚本保持 **ES5**（不用 `let`/`const`、箭头、模板字面量、`?.`、`await`）—— **新增运行时依赖时同步加进页面内能力自检**。
- **启动健壮性 + 排障**：元素默认 `opacity:0`、靠脚本加 `.in`，所以「脚本没起来 = 全黑 + 点不动 + 零提示」。排障顺序：① **先认画面**（看**构图特征**定停在哪一幕）；② 看兜底面板缺失能力；③ 脚本显然在跑 → 查**幕的显隐门控**；④ 核对资源路径大小写；⑤ 探针开 **Network `loadingFailed`**。
