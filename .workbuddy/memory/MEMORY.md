## 项目本体

- 单文件纯静态叙事小游戏，交付 `index.html`（原生 HTML/CSS/JS，零依赖/构建/网络）。画布 **1200×896**，小窗由 `#stage` 等比缩放。
- 素材在 `assets/screen1..7`，路径**正斜杠**。`screen1~5` 已交付，**`screen6/7`=第六幕**（v2.20 结项、未开发）。
- **去掉播放中视频又留背景 → 导出末帧成真实素材**（headless Edge `seek`→`drawImage`→`toDataURL()`）。

## 文档分工

- `01-需求文档.md` 写**做成什么样**、`02-开发计划.md` 写**怎么做**；**不重复数值**，改一份必查另一份。两份**纯 LF 行尾** —— 脚本须「读 bytes→解码→**按 LF 写回**」，否则 diff 全红。

## 协作流程

- 分轮推进：需求 → 整理文档 → **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 「开工」。每轮后追加日志＋`present_files`。
- **多问题模式**：逐项「改 → 跑该问题用例 → commit」，最后跑全量；提交写清问题号与根因。
- **答复语义「顺着 Q 的选项」读**：Q 是选择题时答复里的描述即「选项」——「**是** XX」＝确认；「**怎么** XX」＝报缺陷；**无否定词＝确认**；**拿不准默认不动**。

## 测试约定

**详见技能 `web-visual-verify-cdp`**（只留硬约束）：

- `node .workbuddy/tools/test.js`（CDP 直连 Edge；**14 用例 460 项**）＋ `boot-check.js`（19 项；**注入不可撤销排最后**）。断言前视口钉 1200×896。
- 几何读**布局坐标**（`offsetParent` 链累加），**别用** `getBoundingClientRect()`（被 transform 污染）；素材看 `naturalWidth`（0 即败）。
- **「动作」需求采样 `computed transform`**：`offsetTop` 只管**布局位置**——「**在哪儿**」≠「**怎么到那儿**」。`goal01` 写成「原地放大」仍**23 条全绿**。
- **`gate` 专测整幕可见性+堆叠隔离**；⚠️ `elementFromPoint` 测不出（未激活幕 `pointer-events:none`），**层序用 `zIndex` 数值比**。
- **`.in`＝动画「开始」≠结束**：断言 `opacity` 前先 `waitFor(opacity === 目标值)`——淡入有 300~700ms 窗口。
- **撤场过渡必须短于它配合的「遮蔽动作」**：A 退场慢于 B 入场 → **藏在 B 的透明度里（量 `opacity` 才暴露）**。撤场 ≤ 遮蔽层淡入（`shadow.out` 400ms、`#continue.out` 150ms vs 黑幕 400ms）。**踩两次**：撤卡片/蒙黑层却漏按钮。

## 实现约定

- **幕必须「门控+隔离」两件套**：门控＝`.scene` 自带 `opacity:0`+激活类；隔离＝`isolation:isolate`（否则 `opacity` 0→1 时**堆叠上下文消失**，幕内 z-index 跑到 `#stage` 层）。**新增幕须补、`gate` 覆盖。**
- **「终点」会移动，副作用须复查**：凡「某事件＝全片终点」（如点 `Continue` 停 BGM），终点后移则依赖它的副作用**静默失效**且无断言报。**改流程时搜终点/结束/停止。**
- **收尾撤场（Q43）**：点 `Continue` **同一帧**撤卡片/蒙黑/按钮，与黑幕 400ms 渐入并行；**须列全该幕元素**。
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 幕间注入（`preload=none`）。新幕视频照搬第三幕。**切幕「旧图淡出+新图淡入」同一 `anim()` 同帧交叉，别垫黑场**。
- **第五幕坐标**：`#btn-papers` `705/593`；`#hand5` `791/596`、`z 45`（>纸片 <黑幕），指尖对纸片中心 802.5。
- **视频退役为静帧后 `<video>` 留 DOM 但 `display:none`**。**断言「无视频画面」查布局宽高=0 或 `currentTime===0`，别查 `opacity`**。
- **第六幕拼图（v2.20 结项·未开发）**：`piece-many`(静态底)+9 碎片=`all-picture`；**落点须精扫到 0 误差**（1px 即 9~11 色差）；首次拖拽；C5 **复用第四幕**（`221/120`、`467.5/770`），但**须在 `#act6` 内新建**（`#act4` z=4 遮不住 z=6）且三者**各自门控**；终点＝点 `Continue` 后转黑幕滞留。
- **⚠️ C5 别照抄第四幕（Q55/Q56）**：① **不作 UI 淡出** —— 幕内一切**原样保留、整体被 70% 蒙黑压暗**（`.ui-out` 仅第四幕）；② 两钮**只屏蔽点击**（`pointer-events:none`，**取 `#shadow6` 淡入首帧**），**不可**给 `#act6` 整幕设（C3 拖拽与 `Continue` 都要点）。发光**常驻不熄灭**，「2s」＝进 C5 的等待；③ **参考图两时长勿合并**：自动 **2s** / 手动 **3s**（Q51，两个独立常量）。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100 / slot 110。第五幕内：定格1<室内2<对话30<纸片40<手45<黑幕100。**锁三层** `busy`/`animLock`(250ms)/`placing`；进玩法循环前 `busy=false`。
- **贴纸落点判据（Q25）**：判「整张（142×119 外框）完整落在范围内」而非「中心在」；**高亮 `.on-body` 与判定共用 `inBody()`**；截图有偏移，先标定。
- **最低 Chrome 41+/Edge 15+/Firefox 44+**：脚本保持 **ES5**（禁 `let`/`const`、箭头、模板字面量、`?.`、`await`），新增依赖同步进自检。
- **启动排障**：「脚本没起来＝全黑+点不动」。序：①认画面；②兜底面板；③查**门控/隔离**；④路径大小写；⑤Network。
