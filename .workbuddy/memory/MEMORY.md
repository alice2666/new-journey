## 项目本体

- 单文件纯静态叙事小游戏，交付物只有 `index.html`（原生 HTML/CSS/JS，零依赖/构建/网络，双击即用）。画布 **1200×896**，窗口小由 `#stage` 等比缩放（≤1）。
- 素材在 `assets/screen1..7`，路径用**正斜杠**。`screen1~5` 已接入；**`screen6`/`screen7` 经 Q41 属第六幕**，玩法待描述。
- **去掉播放中视频又留背景 → 导出末帧成真实素材**（headless Edge `seek(末帧)`→`drawImage`→`toDataURL()`）。

## 文档分工

- `01-需求文档.md` 写**做成什么样**、`02-开发计划.md` 写**怎么做**；两份**不重复数值**（数值以需求为准），**改一份必查另一份**。

## 协作流程

- 分轮推进：需求 → 「整理文档」→ **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 最后「开工」。每轮后追加日志＋`present_files`。
- **多问题模式**：逐项「改 → 跑该问题用例 → 看截图 → commit」，最后跑全量；提交写清问题号与根因。
- **答复语义「顺着 Q 的选项」读**（踩两次）：Q 是选择题时答复里的描述即「选项」——「**是** XX」＝确认；「**怎么** XX」＝报缺陷；**无否定词＝确认**。例：Q「BGM 停止点后移？」答「第四幕末停」→选「不动」；**拿不准默认不动**。

## 测试约定

**做法详见技能 `web-visual-verify-cdp`**，只留硬约束：

- `node .workbuddy/tools/test.js`（CDP 直连 Edge；**14 用例 460 项**）＋ `boot-check.js`（4 场景 19 项；**注入不可撤销排最后**）。断言前视口钉 **1200×896**（`s=1`）。
- 几何读**布局坐标**（`offsetParent` 链累加），**别用** `getBoundingClientRect()`（被 transform 污染）；素材真加载看 `naturalWidth`（0 即败）。
- **「动作」需求采样 `computed transform`**（D5）：`offsetTop` 只管**布局位置**——「**在哪儿**」≠「**怎么到那儿**」。`goal01` 要「落下」写成「原地放大」仍**23 条全绿**。解析 `matrix()`（6→`n[4]/n[5]`；16→`n[12]/n[13]`）。
- **`gate` 专测「整幕可见性+堆叠隔离」**；⚠️ `elementFromPoint` 测不出（未激活幕 `pointer-events:none`），**图层顺序改用 `zIndex` 数值比较**。
- **`.in`＝动画「开始」≠结束（D7）**：断言 `opacity` 前先 `waitFor(opacity === 目标值)`——淡入有 300~700ms 窗口。
- **撤场过渡必须短于它配合的「遮蔽动作」（D8）**：A 退场慢于 B 入场 → B 覆盖完时 A 还在场，**藏在 B 的透明度里，截图看不出、只有量 `opacity` 才暴露**。做法：撤场 ≤ 遮蔽层淡入（`shadow.out` 400ms、`#continue.out` 150ms vs 黑幕 400ms）。**踩过两次**：曾撤了卡片/蒙黑层却漏了按钮。

## 实现约定

- **幕必须「门控 + 隔离」两件套**（D4/D6，均「断言全绿但画面错」）：门控＝`.scene` 自带 `opacity:0` + 激活类；隔离＝`.scene` 必须 `isolation:isolate`（否则 `.active` 让 `opacity` 0→1 时**堆叠上下文消失**，幕内 z-index 跑到 `#stage` 层）。**新增幕须补、`gate` 覆盖。**
- **「终点」会移动，副作用须复查**：凡「某事件＝全片终点」（如「点 `Continue` 停 BGM」），终点后移则依赖它的副作用**静默失效**且无断言报。**改流程时搜「终点/结束/停止」。**
- **第四幕收尾（Q43）**：点 `Continue` 的**同一帧**撤 `goal01.in`+`shadow.in`+`continue.in`（均配 `.out`），与黑幕 400ms 渐入并行——否则黑幕跑完仍露卡片/按钮。**「整组撤场」须列全该幕可见元素。**
- **素材里没被提到的图，先登记 + 列 Q，不揣测玩法。**
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 幕间注入（HTML `preload=none` 不带 src）。新幕视频照搬第三幕（`object-fit:fill`）；无定格图→末帧导出法造一张。**切幕把「旧图淡出+新图淡入」放同一 `anim()` 同帧交叉——别垫黑场/串行**。
- **第五幕坐标**：`#btn-papers` `705/593`；`#hand5` `791/596`、`z-index 45`（>纸片 40、<黑幕 100），指尖对纸片中心 802.5、落纸上沿内 3px。
- **视频退役为静帧后 `<video>` 留 DOM 但 `display:none`**。⚠️ **断言「已无视频画面」查布局宽高=0 或 `currentTime===0`，不查 `opacity`**。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100 / slot 110。第五幕幕内：定格1<室内2<对话30<纸片40<手45<黑幕100。**锁三层**：`busy`（演出期屏蔽点击）/`animLock`（250ms）/`placing`（待放置）；进玩法循环前 `busy=false`。
- **贴纸落点判据（Q25）**：判「整张贴纸（142×119 未旋转外框）完整落在范围内」而非「中心在」；**高亮 `.on-body` 与落点判定共用 `inBody()`**。截图有裁切偏移/缩放比不等，先标定再换算。
- **最低 Chrome 41+ / Edge 15+ / Firefox 44+**：脚本保持 **ES5**（不用 `let`/`const`、箭头、模板字面量、`?.`、`await`）；新增依赖须同步进页面能力自检。
- **启动排障**：「脚本没起来＝全黑+点不动+零提示」。序：① 先认画面；② 看兜底面板缺什么；③ 脚本在跑→查**门控/隔离**；④ 核对路径大小写；⑤ 开 Network `loadingFailed`。
