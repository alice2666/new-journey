- 单文件纯静态叙事小游戏，交付 `index.html`（原生 HTML/CSS/JS，零依赖）。画布 **1200×896**，小窗由 `#stage` 等比缩放。
- 素材在 `assets/screen1..7`，路径**正斜杠**。**1~6 幕全部已交付**（第六幕 v2.15 实现 + v2.16/17 微调）。
- **去掉播放中视频又留背景 → 导出末帧成真实素材**（headless Edge `seek`→`drawImage`）。

## 文档分工

- `01-需求文档.md` 写**做成什么样**、`02-开发计划.md` 写**怎么做**；**不重复数值**，改一份必查另一份。两份**纯 LF**；`index.html`/`test.js` 是 **CRLF**（读 bytes→解码→按原行尾写回，否则 diff 全红）。

## 协作流程

- 分轮推进：需求 → 整理文档 → **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 「开工」；每轮后追加日志＋`present_files`。
- **多问题模式**：逐项「改 → 跑该问题用例 → commit」，最后跑全量；提交写清问题号与根因。
- **答复语义「顺着 Q 的选项」读**：「**是** XX」＝确认；「**怎么** XX」＝报缺陷；**无否定词＝确认**；**拿不准默认不动**。

## 测试约定（详见技能 `web-visual-verify-cdp`）

- `node .workbuddy/tools/test.js`（CDP 直连 Edge；**18 用例 780 项**）＋ `boot-check.js`（19 项；**注入不可撤销排最后**）。断言前视口钉 1200×896。
- 几何读**布局坐标**（`offsetParent` 链累加），**别用** `getBoundingClientRect()`（被 transform 污染）；素材看 `naturalWidth`（0 即败）。
- **量「动作」须采样动画期 `computed transform`**：布局坐标在动作期是**常数**；**动作结束后再量＝恒真，等于没测**。
- **「开始」≠「结束」**：断 `opacity` 前先 `waitFor`；`done` 判据若写「回到阈值内」会在**收尾前**置位 → 断言「无残留」须再等一个周期。**撤场 ≤ 它遮蔽层的淡入**，且同帧撤须列全该幕可见元素。
- **「透明」≠「不吃事件」（D9）**：`opacity:0` 不影响命中测试——透明全屏层照样吞整幕 `pointerdown`，而坐标/类名/`opacity` 断言**一条都不失败**。**有过透明态的全屏层必须 `pointer-events:none` 并写断言**；定位靠**事件探针**（挂 `pointerdown` 打印 `e.target.id`）。

## 动画并存（v2.17）

- **同元素两动画＝整体替换、不叠加**：同特异性规则按**后定义者胜** → **静默吃掉一个**（无报错）→ **必须写组合规则 `.pop.glow`**。并存后 `animationName/Duration/IterationCount` 是**逗号列表** → 老断言 `=== 'picGlow'` **假红**，改**按名字取索引**。
- **别用 `animationend` 摘类**（会重启并存的另一动画、相位归零 → 可见闪）；一次性动画播完自动回落，**只加不摘**。
- **「等前一个过渡走完再动」写进 keyframes（前 N% 原地不动）**，别用 `animation-delay`+`fill-mode`。

## 实现约定

- **幕必须「门控+隔离」两件套**：门控＝`.scene` 自带 `opacity:0`+激活类；隔离＝`isolation:isolate`（否则 `opacity` 0→1 时**堆叠上下文消失**，幕内 z-index 跑到 `#stage` 层）。**新增幕须补。**
- **「终点」会移动，副作用须复查**：凡「某事件＝全片终点」（如点 `Continue` 停 BGM），终点后移则依赖它的副作用**静默失效**且无断言报。**改流程时搜终点/结束/停止。**
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 幕间注入。**切幕「旧图淡出+新图淡入」同一 `anim()` 同帧交叉，别垫黑场**。视频退役为静帧后 `<video>` 留 DOM 但 `display:none`——**断「无视频画面」查布局宽高=0 或 `currentTime===0`，别查 `opacity`**。
- **第六幕拼图**：`piece-many`(静态底)+9 碎片=`all-picture`；**落点须精扫到 0 误差**（1px 即 9~11 色差）；**全片首次拖拽**（`HIT_TOLERANCE=30`、落点必走 `toStage(e)`；两个 up 事件**绑 `#stage`**+`setPointerCapture`）；坐标见 §5.5（**`08-03` 底板 `left=884` 是唯一不居中项**）。
- **⚠️ C5 别照抄第四幕（Q55/Q56）**：① **不作 UI 淡出**——幕内一切**原样保留、整体被 70% 蒙黑压暗**；② 两钮**只屏蔽点击**，**不可**给 `#act6` 整幕设（拖拽与 `Continue` 都要点）；发光**常驻**，「2s」＝进 C5 的等待；③ 参考图**自动 2s／手动 3s 勿合并**；④ 坐标同第四幕 `221/120`、`467.5/770`，但**须在 `#act6` 内新建**且三者**各自门控**。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100。**锁三层** `busy`/`animLock`/`placing`；进玩法循环前 `busy=false`。
- **贴纸落点**：判「整张 142×119 外框完整落在范围内」；**高亮与判定共用 `inBody()`**。
- **最低 Chrome 41+**：脚本保持 **ES5**（禁 `let`/`const`、箭头、模板字面量、`?.`、`await`）。
- **启动排障**：「脚本没起来＝全黑+点不动」→ ①认画面 ②兜底面板 ③查门控/隔离。
- **复用相邻实现先列差异表**：「照搬第四幕」类需求常含**做法相反**项；**文档里贴的代码会过期**，同步时回查 `index.html`。自检 `validate_v215.py`（`validate_v214.py` 守计划态，实现后必失败，预期内）。
