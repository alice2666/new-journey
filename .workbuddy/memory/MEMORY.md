## 协作流程

- 分轮推进：需求 → 整理文档 → **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 「开工」；每轮后追加日志＋`present_files`。
- **多问题模式**：逐项「改→跑该用例→commit」，最后跑全量；提交写清问题号与根因。
- **答复「顺着 Q 的选项」读**：「**是** XX」＝确认；「**怎么** XX」＝报缺陷；**无否定词＝确认**；**拿不准默认不动**。

## 测试约定（详见技能 `web-visual-verify-cdp`）

- `.workbuddy/tools/test.js`（CDP 直连 Edge；**18 用例 780 项**）＋ `boot-check.js`（19 项，注入不可撤销排最后）。断言前视口钉 1200×896。
- **验策略须先拿掉放宽它的 flag**：`test.js` 带 `--autoplay-policy=no-user-gesture-required`，拿它测自动播放**必假**（探针 `probe-bgm2.js` 不传才准）。
- 几何读**布局坐标**（`offsetParent` 链累加），**别用** `getBoundingClientRect()`（被 transform 污染）；素材看 `naturalWidth`。
- **量「动作」采样动画期 `computed transform`**：布局坐标在动作期是**常数**，**结束后再量＝恒真**。
- **「开始」≠「结束」**：断 `opacity` 前先 `waitFor`；`done` 写「回到阈值内」会**收尾前置位** → 断言「无残留」须再等一周期。**撤场 ≤ 它遮蔽层的淡入**；同帧撤须列全该幕可见元素。
- **「透明」≠「不吃事件」（D9）**：`opacity:0` 不影响命中测试——透明全屏层照样吞整幕 `pointerdown`，而坐标/类名/`opacity` 断言**一条都不失败**。**有过透明态的全屏层必须 `pointer-events:none` 并写断言**；定位靠**事件探针**。
- **动画并存**：同元素两动画＝**整体替换、不叠加**，同特异性按**后定义者胜**→**静默吃掉一个**→**必须写组合规则**（如 `.pop.glow`）；并存后 `animationName/Duration/IterationCount` 变**逗号列表**（整串比较**必假红**）→**按名字取索引**。**别用 `animationend` 摘类**（重启并存动画→可见闪），一次性动画**只加不摘**；「等前一过渡走完再动」**写进 keyframes 前 N%**。

## 实现约定

- **幕必须「门控+隔离」**：门控＝`.scene` 自带 `opacity:0`+激活类；隔离＝`isolation:isolate`（否则 `opacity` 0→1 时**堆叠上下文消失**，幕内 z-index 跑到 `#stage`）。**新增幕须补。**
- **「终点」会移动，副作用须复查**：凡「某事件＝全片终点」（如点 `Continue` 停 BGM），终点后移则依赖它的副作用**静默失效**且无断言报。**改流程时搜「终点/结束/停止」。**
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 幕间注入。**切幕「旧图淡出+新图淡入」同一 `anim()` 同帧交叉，别垫黑场**。视频退役为静帧后 `<video>` 留 DOM 但 `display:none`——**断「无视频画面」查布局宽高=0／`currentTime===0`**。
- **第六幕**：`piece-many`+9 碎片=`all-picture`；**落点精扫到 0 误差**（1px 即 9~11 色差）；**全片首次拖拽**（`HIT_TOLERANCE=30`、落点必走 `toStage(e)`；up 事件**绑 `#stage`**+`setPointerCapture`）；`08-03` 底板 `left=884` 是唯一不居中项。**⚠️ C5 勿照抄第四幕**：①**不作 UI 淡出**（幕内**原位保留、整体被 70% 蒙黑压暗**）；②两钮**只屏蔽点击**（**不可**给 `#act6` 整幕设）；③发光**常驻**（「2s」＝进 C5 的等待）；④参考图**自动 2s／手动 3s 勿合并**；⑤坐标同第四幕但**须在 `#act6` 内新建**、各自门控。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100。**锁三层** `busy`/`animLock`/`placing`；进玩法循环前 `busy=false`。
- **贴纸落点**：判「整张 142×119 外框完整落在范围内」；**高亮与判定共用 `inBody()`**。
- **最低 Chrome 41+**：脚本保持 **ES5**（禁 `let`/`const`、箭头、模板字面量、`?.`、`await`）。
- **启动排障**：「脚本没起来＝全黑+点不动」→ ①认画面 ②兜底面板 ③查门控/隔离。
- **复用相邻实现先列差异表**：「照搬第四幕」类需求常含**做法相反**项；**文档贴的代码会过期**，须回查 `index.html`。
