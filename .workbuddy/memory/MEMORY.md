## 项目本体

- 单文件纯静态叙事小游戏，交付物只有 `index.html`（原生 HTML/CSS/JS，零依赖、零构建、零网络，双击即用）。画布 **1200×896**，窗口小由 `#stage` 等比缩放。
- 素材在 `assets/screen1..7`，路径用**正斜杠**。`screen1~5` 已接入；**`screen6`/`screen7` 经 Q41 属第六幕**，玩法待描述。
- **`screen5/outdoor-still.png`（v2.13）＝ 视频末帧导出的 1200×896 静帧**：「去掉播放中的视频又留户外背景」用**导出末帧成真实素材**最稳（headless Edge `seek(末帧)` → `canvas.drawImage` → `toDataURL()`）。

## 文档分工

- `01-需求文档.md` 写**做成什么样**、`02-开发计划.md` 写**怎么做**；两份**不重复数值**（计划凡数值都标需求章节号），**改一份必查另一份**。

## 协作流程

- 分轮推进：需求 → 「整理文档」→ **说「不要开发」就不写代码** → 逐轮回 1–3 个待确认项 → 最后「开工」。每轮后追加日志 + `present_files` 预览。
- **多问题模式**：**逐项「改 → 跑该问题用例 → 看截图 → commit」**，最后跑全量；提交信息写清问题编号与根因。
- **答复语义「顺着 Q 的选项」读**（已踩两次）：Q 是选择题时答复里的描述就是「选项」——「**是** XX」＝确认；「**怎么** XX」＝报缺陷；**无否定词＝确认**。实例：Q「BGM 停止点后移？」答「第四幕末停、后面没 BGM」→**选「不动」**。**拿不准默认「不动」**。

## 测试约定

**做法详见技能 `web-visual-verify-cdp`**，只留硬约束：

- `node .workbuddy/tools/test.js`（CDP 直连 Edge；**14 用例 447 项**）＋ `boot-check.js`（4 场景 19 项；**注入不可撤销排最后**）。断言前视口钉成 **1200×896**（`s=1`）。
- 几何读**布局坐标**（`offsetParent` 链累加），**别用** `getBoundingClientRect()`（被 transform 污染）；判素材真加载看 `naturalWidth`（`0` 即败）。
- **「动作」需求采样 `computed transform`**（D5）：`offsetTop` 只管**布局位置**——「**在哪儿**」≠「**怎么到那儿**」。`goal01` 要「落下」写成「原地放大」，**23 条断言全绿**。解析 `matrix()` 按槽位取（6→`n[4]/n[5]`；16→`n[12]/n[13]`）。**拍中途**先 `setPlaybackRate(0.12)`。
- **`gate` 用例专测「整幕可见性 + 堆叠隔离」**；⚠️ `elementFromPoint` 测不出（未激活幕 `pointer-events:none`）。
- **`.in` = 动画「开始」≠ 结束（D7）**：断言 `opacity` 前先 `waitFor(opacity === 目标值)`——淡入有 300~700ms 窗口，**不能用类名代替终态**。
- **「图层顺序」需求用 `zIndex` 数值比较断言**，**别用 `elementFromPoint`**（被压元素若 `pointer-events:none`，命中跳过）。

## 实现约定

- **幕必须「门控 + 隔离」两件套**（D4/D6，皆「断言全绿但画面错」）：**门控**＝每个 `.scene` 自带 `opacity:0` + 激活类；**隔离**＝`.scene` 必须 `isolation:isolate`（否则 `.active` 把 `opacity` 0→1 时**堆叠上下文消失**，幕内高 z-index 跑到 `#stage` 层）。**新增幕须补齐、`gate` 覆盖。**
- **「终点」会移动，副作用须复查**（v2.12）：凡「某事件＝全片终点」（如「点 `Continue` 停 BGM」），终点一后移依赖它的副作用**静默失效**且无断言报。**改流程顺序时搜「终点/结束/停止」。**
- **素材里没被提到的图，先登记 + 列 Q，不揣测玩法、不动。**
- **分幕预加载**：首屏只加载第一、二幕；`<video>` 的 `src` 由 JS 在幕间注入（HTML `preload="none"` 不带 src）。新幕视频照搬第三幕（`object-fit:fill`）；**无定格图 → 用上面方法造一张**。**切幕把「旧图淡出+新图淡入」放进同一 `anim()` 同帧交叉——别垫黑场、别串行**。
- **视频退役为静帧后 `<video>` 留 DOM 但 `display:none`**（识别/体检不受影响）。⚠️ **断言「已无视频画面」查布局宽高=0 或 `currentTime===0`，不能查 `opacity`**（`display:none` 下仍是 1）。
- **层叠模型**：`#act1` auto / `#act2`~`#act6` 取幕号 / `#blackout` 100 / slot 110。第五幕幕内：户外定格 1 < 室内 2 < 对话 30 < 纸片 40 < **引导手 45** < 黑幕 100。**锁三层**：`busy`（演出期屏蔽点击）/ `animLock`（250ms）/ `placing`（待放置）；进玩法循环前须 `busy=false`。
- **贴纸落点判据（Q25）**：判「**整张贴纸（142×119 未旋转外框）完整落在范围内**」而非「中心在范围内」；**跟随高亮 `.on-body` 与落点判定共用 `inBody()`**。截图有裁切偏移、缩放比不等，**先标定再换算**（用已知坐标元素解 s 与偏移）。
- **最低 Chrome 41+ / Edge 15+ / Firefox 44+**：脚本保持 **ES5**（不用 `let`/`const`、箭头、模板字面量、`?.`、`await`）；新增运行时依赖须同步加进页面内能力自检。
- **启动排障**：元素默认 `opacity:0` 靠脚本加 `.in`，故「脚本没起来 = 全黑 + 点不动 + 零提示」。序：① **先认画面**（看构图特征定停在哪幕）；② 看兜底面板缺什么；③ 脚本在跑 → 查**幕的门控/隔离**；④ 核对路径大小写；⑤ 开 Network `loadingFailed`。
