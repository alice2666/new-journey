# New Journey · Interactive Narrative

*—— 一个交互式叙事小游戏（8 幕）*

一个用**单文件纯静态 HTML** 实现的叙事互动小游戏。从出发前的房间，到旅途中的行李箱、古堡、修复古画，最终走向终幕的 `THE END` —— 全片共 **8 幕**，含两段背景音乐与全场交互。

🔗 **在线试玩**：`https://alice2666.github.io/new-journey/`

> 打开后点击 **START** 开始。纯静态、零依赖，无需安装任何环境。

## 操作说明

| 幕 | 内容 | 操作 |
|---|---|---|
| 第一幕 | 开场 | 点击 **START** |
| 第二幕 | 房间与对话 | 点击推进台词 |
| 第三幕 | 行李箱整理 | **点击选中**贴纸 → **点击目标位置**放置 |
| 第四幕 | 旅途过渡 | 点击 `Continue` 推进 |
| 第五幕 | 踏入古堡 | 点击纸片拾取，跟随引导手 |
| 第六幕 | 修复古画 | **拖拽**碎片拼合（共 9 片，分 3 波投放） |
| 第七幕 | 抉择 | 点击两枚按钮之一 |
| 第八幕 | 终幕 | 观看 `THE END` |

> 💡 首次进入**必须点击 START** 才会播放音乐 —— 这是浏览器的自动播放策略限制，属于正常行为。

## 技术说明

- **单文件纯静态**：全部逻辑集中在 `index.html`，原生 HTML / CSS / JavaScript，**零第三方依赖、无构建步骤**。
- **固定内部坐标系**：画布 `1200 × 896`，通过 `transform: scale()` 等比缩放适配任意窗口尺寸，内部坐标不被挤压。
- **分幕门控与层叠隔离**：每一幕是独立的全屏绝对定位层，靠「门控类 + `isolation: isolate`」保证任一时刻只有当前幕可见且互不穿透。
- **音频策略**：两段 BGM（第一段「旅途主题」、第二段「古堡主题」）各用独立 `Audio` 实例，避免互相干扰；含自动播放被拒后的补播处理。
- **兼容性**：脚本保持 **ES5** 写法（`var` / `function`），最低支持 **Chrome 41+**。
- **健壮性**：内置启动兜底与故障自诊断 —— 素材缺失或浏览器版本过旧时，会显示带明确原因与失败路径的提示面板，而不是白屏。

## 质量保障

本项目在开发期配有一套基于 **Chrome DevTools Protocol** 的自动化视觉验收脚本（零安装，直连系统 Edge / Chrome），覆盖全片 8 幕的完整交互链路：

- **20 个用例、916 项断言** —— 覆盖全片流程、坐标几何、动画采样、BGM 生命周期与像素级截图体检。
- **19 项启动自检** —— 验证启动兜底与故障自诊断（素材 404、旧引擎、缩放适配等场景）。
- **独立自动播放探针** —— 用于验证浏览器自动播放策略下的真实表现。

> 验收脚本属于开发过程产物，未随本仓库发布；完整的方法论、坐标总表与逐版交付记录可参阅 [`docs/02-开发计划.md`](docs/02-开发计划.md)。

## 运行方式

**方式一 · 直接打开**：双击 `index.html` 即可（`file://` 协议下可完整运行）。

**方式二 · 本地服务**（若浏览器对本地文件有限制）：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。
